# design-5-workout-entry

Design: correction sheet with RPE, technique and pain, correcting any set, and the timed-set clock

**Complexity:** low. Owner's request of 2026-11-05.

Run by the orchestrator, not as a Workflow milestone. It stays `idea` so `/milestone-plan` never picks it, and is set to `done` by hand when finished.

Draw on the Claude Design pages, one board per state, at font 1.0 and 2.0, dark and light:

1. The correction sheet with RPE, technique and pain.
2. How to open it from any logged set in the running workout.
3. The clock on a timed set: before Start, running, past the target, stopped with the time filled in.
4. What happens if a rest is running when Start is tapped, and whether the rest starts after the set is logged.

Update the rule on board D31, which allows correcting only the last set.
